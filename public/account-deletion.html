Permintaan Penghapusan Akun & Data

Kepatuhan Privasi Google Play Console & Apple App Store
Peringatan Penting: Penghapusan akun bersifat permanen dan tidak dapat dibatalkan. Jika Anda masih memasang aplikasi Rimba di ponsel Anda, Anda juga dapat menghapus akun secara instan (0 detik) melalui menu Profil / Pengaturan → Hapus Akun & Data Suaka.

Data yang Dihapus Secara Permanen:

  • Kredensial autentikasi (Email & ID Pengguna di Supabase Auth).
  • Profil Ranger (Nama tampilan, bio, foto avatar di Storage).
  • Seluruh data pulau 3D, tanaman, koin Soul, dan riwayat sesi fokus di awan (game_saves).

Waktu Pemrosesan: Seketika (melalui tombol di dalam aplikasi) atau maksimal 24–48 jam melalui formulir web ini. Tidak ada data pribadi yang disimpan setelah penghapusan selesai.

Data Permanently Deleted:

  • Authentication credentials (Email & User ID in Supabase Auth).
  • Ranger Profile (Display name, bio, avatar image in Storage).
  • All 3D island diorama layouts, flora, Soul coins, and cloud focus session history (game_saves).

Retention & Processing Period: Instant (via in-app Settings button) or within 24–48 hours via this web request portal. Zero personal data is retained post-deletion.
